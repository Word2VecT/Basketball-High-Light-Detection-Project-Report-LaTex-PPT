## 1. pipeline.py - 主流程配置

**文件位置**: `/data/ljy23/project/code/src/track/pipeline.py`

| 参数名 | 默认值 | 位置 | 说明 |
|--------|--------|------|------|
| `OUTPUT_ROOT` | `"./test"` | 第 365 行 | 输出根目录，所有结果都保存在这里 |
| `FRAME_INTERVAL` | `300` | 第 366 行 | 每个片段处理的帧数（不包含重叠） |

| `MAX_PROCESS_SEGMENTS` | `3` | 第 369 行 | 最大处理的片段数量 |
| `START_VIDEO_FRAME` | `3500` | 第 370 行 | 视频处理的起始帧号 |
| `DISTANCE_THRESHOLD` | `0.7` | 第 371 行 | 轨迹匹配的距离阈值（米） |

## 快速修改建议

### 如果你想调整处理速度：

1. **减小处理帧数**：修改 `FRAME_INTERVAL`（第 366 行）
2. **调整重叠帧数**：修改 `OVERLAP_FRAMES`（第 367 行）
3. **减小批量大小**：修改 `BATCH_SIZE`（第 351 行）

### 如果你想调整轨迹质量：

1. **调整检测阈值**：修改 `DETECTION_CONF_THRESH`（第 343 行）
2. **调整匹配距离**：修改 `DISTANCE_THRESHOLD`（第 371 行）
3. **调整平滑参数**：修改 `traj_smooth.py` 中的相关参数

### 如果你想调整融合效果：

1. **调整重叠要求**：修改 `min_overlap_frames` 和 `min_overlap_ratio`（第 685-686 行）
2. **调整融合权重**：修改 `confidence_weight`（第 689 行）

---

## 注意事项

1. **修改配置前请备份原文件**
2. **建议先在小数据集上测试**
3. **大部分参数都可以在 pipeline.py 的调用处覆盖，无需修改模块源码**
4. **修改后运行 `python -m src.track.pipeline` 启动处理**
